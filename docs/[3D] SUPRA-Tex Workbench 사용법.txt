* [3D] SUPRA-Tex Workbench 사용법


1. 소개

- SUPRA-Tex Workbench 는 이미 있는 3D 메시에, 같은 물체를 찍은 이미지 한 장을 기준으로 PBR 텍스처(색, 거칠기, 금속성)를 입혀 주는 프로그램입니다. 이미지에 보이는 면은 이미지를 따르고, 안 보이는 옆면과 뒷면은 AI 가 채웁니다.

- 브라우저 화면에서 씁니다. 메시와 이미지를 끌어다 놓고 버튼을 누르면 결과 GLB 가 나옵니다.

- 메시는 어떤 방법으로 만든 것이든 쓸 수 있습니다. Pixal3D, Idol 같은 AI 결과나 직접 만든 메시도 됩니다.

- 원본 SUPRA-Tex 는 리눅스 전용이고 재질 모델이 비상업용(Qwen)입니다. 이 프로그램은 아래처럼 바꾼 버전입니다.
+ 윈도우에서 RTX 20 시리즈부터 50 시리즈까지 돌아가게 했습니다.
+ 재질 모델을 상업적 사용이 가능한 SuperMat 으로 바꿨습니다.
+ 8GB 그래픽카드에서도 돌아가게 메모리 사용을 줄였습니다. 정밀도는 RTX 30 이상은 bf16, RTX 20 은 fp16 으로 자동으로 고릅니다.
+ 메시와 이미지의 각도를 자동으로 맞추고, 결과를 원래 메시 위치로 되돌립니다.
+ 피부, 천처럼 금속이 아닌 곳이 번들거리지 않게 금속성과 거칠기를 보정합니다.

- 필요한 사양
+ NVIDIA RTX 20 시리즈 이상, VRAM 8GB 이상
+ 그래픽 드라이버 : CUDA 12.8 을 지원하는 버전 (2번 참고)
+ 저장 공간 : 약 25GB (전용 파이썬 환경 약 7GB + 모델 약 17GB)

- 확인된 장비
+ RTX 3060 12GB : 메시 + 이미지 한 번에 약 6분
+ RTX 2070 SUPER 8GB : 텍스처 굽기 단계 첫 실행 약 46분(GPU 코드 컴파일 포함), 두 번째부터 약 5분 30초


2. 준비물 설치

- 그래픽 드라이버를 확인합니다. cmd 에서 아래 줄을 실행하고, 오른쪽 위 CUDA Version 이 12.8 이상인지 봅니다. 낮으면 NVIDIA 홈페이지에서 최신 드라이버를 설치하세요.

nvidia-smi

- Git 이 설치되어 있어야 합니다. ComfyUI 포터블 설치 및 설정 문서의 Git 설치를 참고하세요.

- SUPRA-Tex 전용 파이썬 3.14 를 설치합니다. ComfyUI 의 파이썬과는 별개입니다. 이미 설치했다면 건너뛰세요.
+ 아래 주소에서 Windows installer (64-bit) 인 python-3.14.10-amd64.exe 를 받아 실행합니다.

https://www.python.org/downloads/release/python-31410/

- 첫 화면의 Use admin privileges 와 Add python.exe to PATH 는 둘 다 체크하지 마세요. 다른 파이썬과 섞이지 않게 하기 위해서입니다.

- Customize installation 을 누릅니다. Optional Features 화면은 그대로 Next 를 누릅니다.

- Advanced Options 화면에서 free-threaded 관련 항목이 있으면 체크하지 말고, 설치 위치를 아래로 바꾼 뒤 Install 을 누릅니다.

D:\Programs\Python\Python314

- C 드라이브의 C:\Programs\Python\Python314 에 설치해도 됩니다. 설치 파일이 두 위치를 모두 찾습니다. C 드라이브가 SSD인 경우 용량 문제로 D 드라이브 설치를 권장합니다.


3. SUPRA-Tex 설치

- 설치할 폴더를 만듭니다. 이 설명서는 C:\Programs 를 기준으로 합니다. D:\Programs 에 설치해도 됩니다. 경로에 한글이 없어야 합니다.

- C:\Programs 폴더의 주소창에 cmd 를 입력해 검은색 창을 열고 아래 줄을 실행합니다.
+ 붙여넣을 때는 마우스 우클릭을 하세요.

git clone https://github.com/Supra-3D/SUPRA-Tex.git

- 아래 줄로 받은 폴더 안으로 들어가고, 워크벤치가 맞춰 둔 버전으로 고정합니다.

cd SUPRA-Tex

git checkout --detach cee4435652d0f23737bd28d5704e0fae9830b411

- 아래 주소에서 Code > Download ZIP 으로 SUPRA-Tex Workbench 를 받아 풉니다.

https://github.com/Linchwe/SUPRA-Tex-Workbench-Windows

- 푼 폴더 안의 overlay 폴더를 열고, 그 안의 내용을 모두 아래 폴더에 넣고 덮어쓰기를 고릅니다. overlay 폴더에는 실행 파일 2개, 워크벤치(workbench 폴더), 재질 모델 코드, 윈도우용 패치, 테스트 파일이 들어 있습니다.

C:\Programs\SUPRA-Tex

- 같은 폴더의 Setup-SUPRA-Tex.cmd 를 더블클릭합니다. 아래 7단계를 자동으로 진행합니다. PyTorch 등 약 7GB 를 받으므로 시간이 걸립니다.
+ 1/7 SUPRA-Tex 버전 확인
+ 2/7 Python 3.14 찾기
+ 3/7 전용 파이썬 환경(.venv314) 만들기
+ 4/7 PyTorch 와 Triton 설치
+ 5/7 패키지와 SUPRA-Tex 설치
+ 6/7 CUDA 확장 설치 (RTX 20~50 지원 윈도우용 빌드)
+ 7/7 설치 확인

- 마지막에 "Setup finished / 설치 완료" 가 나오면 끝입니다. 7/7 줄에 내 그래픽카드 이름과 CUDA True 가 나와야 합니다.
+ 끝의 괄호는 그래픽카드 세대입니다. RTX 20 은 (7, 5), RTX 30 은 (8, 6), RTX 40 은 (8, 9), RTX 50 은 (12, 0) 입니다.

- 중간에 멈추면 어느 단계에서 멈췄는지 나옵니다. 창의 마지막 30줄을 복사해서 LLM 모델에 공유해 주세요. 고친 뒤 다시 실행하면 이미 끝난 단계는 빠르게 넘어갑니다.


4. 워크벤치 실행

- ComfyUI 등 그래픽카드를 쓰는 프로그램을 모두 끕니다. 8GB 에서는 VRAM 이 빠듯합니다.

- C:\Programs\SUPRA-Tex 폴더의 Start-SUPRA-Tex.cmd 를 더블클릭합니다. 검은색 실행 창이 뜨고, 브라우저에 아래 주소가 열립니다.

http://127.0.0.1:8390

- 브라우저가 저절로 열리지 않으면 위 주소를 직접 입력하세요.

- 처음에는 메뉴가 영어로 나옵니다. 왼쪽 아래 "한국어" 버튼을 누르면 한국어로 바뀌고, 다음에 열 때도 한국어로 나옵니다. 아래 설명의 메뉴 이름은 영어판 이름이고, 괄호 안은 한국어판 이름입니다.

- 끌 때는 왼쪽 아래 "Close workbench"(워크벤치 끄기)를 누릅니다.
+ 작업이 돌고 있으면 멈추고 끌지 묻는 창이 뜹니다. 확인을 누릅니다.
+ 화면에 꺼졌다는 안내가 나오면 브라우저 탭과 검은색 실행 창을 닫습니다.

- 브라우저 창만 닫으면 프로그램은 계속 켜져 있습니다. 다시 열 때는 위 주소를 다시 열면 됩니다.

- 검은색 실행 창을 X 로 닫으면 워크벤치는 꺼지지만, 굽기 중이었다면 계산 프로세스가 남아 VRAM 을 계속 차지할 수 있습니다. "Close workbench"(워크벤치 끄기) 버튼으로 끄는 것이 가장 확실합니다. 이미 창을 닫았다면 작업 관리자 > 성능 > GPU 에서 전용 GPU 메모리를 보고, 계속 차 있으면 세부 정보 탭에서 python.exe 를 끝냅니다.


5. 첫 테스트 (설치 확인)

- 함께 들어 있는 식물 예제로 설치가 제대로 되었는지 확인합니다. 예제 메시는 일부러 크기, 위치, 각도를 틀어 둔 것이라 자동 맞춤도 같이 확인할 수 있습니다.

- 왼쪽 "Bake texture"(텍스처 굽기) 화면의 01 Input (입력) 칸에 아래 두 파일을 끌어다 놓습니다. 파일은 C:\Programs\SUPRA-Tex\mesh_texture_test 폴더에 있습니다.
+ Mesh (메시) 칸 : test_pitcher_moved.glb
+ Image (이미지) 칸 : pitcher_cond.png

- 02 Settings (설정)은 그대로 두고 "Start baking"(텍스처 굽기 시작)을 누릅니다.

- 첫 실행은 오래 걸립니다. 화면이 한동안 멈춘 것처럼 보여도 끄지 마세요.
+ 모델 약 17GB 를 C:\Programs\SUPRA-Tex\models 에 받습니다. (SUPRA-Tex 3D 보완 모델, TRELLIS.2 VAE, Stable Diffusion 2.1, SuperMat)
+ GPU 코드를 컴파일합니다. RTX 20 시리즈는 40분 이상 걸릴 수 있습니다.
+ 두 번째부터는 받아 둔 모델과 컴파일해 둔 코드를 써서 5~6분 정도로 줄어듭니다.

- 끝나면 아래가 보이면 정상입니다.
+ 진행 칸 5단계가 모두 초록색이고 "Done"(완료)
+ 03 Fit check (맞춤 확인) : 겹침(IoU) 0.94 정도, 보정 회전 좌우 -7.5도 정도
+ 04 Result (결과) : 텍스처가 입혀진 식물이 3D 로 보임


6. 메시와 이미지 준비

- 메시
+ 형식 : GLB / OBJ / PLY / STL (최대 512MB)
+ 방향 : 블렌더 Front 뷰(넘패드 1)에서 물체의 정면이 화면을 보고, 위쪽이 Z 축을 향해야 합니다. 블렌더에서 File > Export > glTF 2.0 (.glb) 를 기본 설정(+Y Up 켬) 그대로 내보내면 맞습니다.
+ 조금 덜 맞아도 좌우 10도, 위아래 5도 안쪽은 자동으로 바로잡습니다.

- 이미지
+ 메시와 같은 물체를 정면에서 본 이미지여야 합니다.
+ 배경을 지운 투명 PNG 여야 합니다. 배경이 있으면 올릴 때 거부됩니다.
+ 상반신처럼 이미지 가장자리에서 잘린 그림도 됩니다.

- 어떤 메시가 잘 맞는지
+ Pixal3D, Idol : 이미지에 맞춰 형상을 만드는 방식이라 텍스처 위치가 잘 맞습니다. 가장 추천합니다.
+ 디테일을 새로 다듬은 메시 : 형상은 선명하지만, 목걸이 같은 잔 장식이 이미지와 위치가 달라지면 그 부분의 텍스처가 어긋날 수 있습니다. 눈, 코, 입 같은 큰 형태는 대체로 맞습니다.


7. 텍스처 굽기

- 01 Input (입력)
+ Mesh (메시) 칸 : 6번에서 준비한 메시를 끌어다 놓거나 눌러서 고릅니다.
+ Image (이미지) 칸 : 배경을 지운 이미지를 넣습니다.

- 02 Settings (설정) : 처음에는 그대로 쓰세요.
+ Rotate mesh (메시 방향 돌리기) : 메시가 옆이나 뒤를 보고 있을 때 90°, 180°, 270° 로 돌립니다.
+ Field of view (화각) : Auto (자동). 사람 흉상처럼 화각을 정하기 어려운 물체는 좁은 화각을 고릅니다.
+ Metallic correction (금속성 보정) : 0.45. 이 값보다 낮은 금속성은 0(비금속)으로 내립니다. 금속이 덜 잡히면 0.35 로 낮춥니다. 0 이면 끕니다.
+ Roughness correction (거칠기 보정) : 0.6. 금속이 아닌 곳의 거칠기가 이 값보다 낮으면 이 값으로 올려 번들거림을 없앱니다. 유리처럼 원래 매끈한 물체는 0 으로 끕니다.
+ Max faces (면 수 상한) : 500,000. 결과 메시의 면 수입니다.
+ Seed (시드) : 비워 두면 기본값. 숫자를 바꾸면 안 보이는 면을 다르게 채웁니다.
+ Auto-correct small rotations (작은 회전 자동 보정) : 켬
+ File is Z-up (Z 가 위쪽인 파일) : 끔. 위쪽이 Z 축으로 저장된 파일일 때만 켭니다.
+ Return result to the original mesh position (결과를 원래 메시 위치로 되돌리기) : 켬. 결과가 원래 메시와 같은 위치, 크기, 방향으로 나와서 블렌더에서 겹쳐 볼 수 있습니다.

- "Fit preview (about 1 min)"(맞춤 미리보기 (약 1분))를 누르면 그래픽카드 없이 카메라 맞춤만 해서 03 Fit check (맞춤 확인)에 보여 줍니다. 처음 쓰는 메시는 이걸로 먼저 확인하는 것을 추천합니다.

- "Start baking"(텍스처 굽기 시작)을 누르면 아래 5단계를 진행합니다. 진행 칸에 지금 단계와 걸린 시간이 나옵니다.
+ 1. Read mesh (메시 읽기)
+ 2. Fit camera (카메라 맞추기)
+ 3. Material maps (재질 지도) : SuperMat
+ 4. Bake texture (텍스처 굽기) : SUPRA-Tex. 가장 오래 걸립니다.
+ 5. Save (저장)

- 멈추려면 "Stop task"(작업 멈추기)를 누릅니다.

- 진행 칸 아래 "Task log"(작업 로그)를 열면 자세한 진행 내용이 보입니다.


8. 결과 확인과 받기

- 03 Fit check (맞춤 확인)
+ 이미지 위에 빨간 선으로 메시 윤곽이 그려집니다. 물체 테두리와 맞으면 정상입니다.
+ 겹침(IoU)이 0.9 이상이면 잘 맞은 것입니다.
+ 0.8 보다 낮으면 안내가 나옵니다. 작업 로그에 "--yaw 180" 처럼 방향 안내가 있으면 Rotate mesh (메시 방향 돌리기)를 그 값으로 바꿔 다시 실행합니다.

- 04 Result (결과)
+ 결과가 3D 로 나옵니다. 마우스 왼쪽 드래그로 돌리고, 휠로 확대하고, 오른쪽 드래그로 옮깁니다.
+ "Download result GLB"(결과 GLB 받기)를 누르면 메시이름_tex.glb 로 받아집니다. (보통 다운로드 폴더)

- 결과 메시
+ SUPRA-Tex 가 원래 메시 모양을 따라 폴리곤과 UV 를 새로 짠 메시입니다. 모양은 같지만 원래 메시의 폴리곤과 UV 는 남지 않습니다.
+ 원래 폴리곤과 UV 에 텍스처가 필요하면 블렌더에서 Bake_PBR_HighToLow.py 로 원래 메시에 구워 옮깁니다.
+ 텍스처는 4096 크기의 색 지도와 금속성·거칠기 지도입니다.


9. 작업 기록과 저장 공간 정리

- 작업마다 입력, 맞춤 결과, 로그, 결과 GLB 가 아래 폴더에 저장됩니다.

C:\Programs\SUPRA-Tex\workbench_data

- 왼쪽 "Task history"(작업 기록)에서 지난 작업을 "Open →"(열기 →)로 다시 열어 결과를 보고 받을 수 있습니다. "Delete"(지우기)로 하나씩 지울 수 있습니다.

- 필요한 결과 GLB 를 받은 뒤에는 정리하는 것을 추천합니다. "Task history"(작업 기록) 화면 오른쪽 위 "Clear history"(기록 정리)를 누르고, 지울 개수와 용량이 나오면 확인을 누릅니다.
+ 작업 기록과 올린 파일이 모두 지워집니다.
+ 브라우저로 받은 결과 GLB(다운로드 폴더)는 지워지지 않습니다.
+ 모델(models 폴더)과 파이썬 환경(.venv314)은 지우지 않습니다.
+ 작업이 돌고 있으면 지우지 않고 안내만 나옵니다.


10. 오류가 났을 때

- 작업이 실패하면 진행 칸에 "Failed"(실패)가 나오고 작업 로그가 열립니다. 로그의 마지막 30줄을 복사해서 LLM 모델에 공유해 주세요.

- 이미지를 넣을 때 "no transparent background" (투명 배경이 없습니다) : 배경을 지운 PNG 를 넣으세요.

- Setup 에서 "Python 3.14 was not found" : 2번처럼 Python 3.14 를 C:\Programs\Python\Python314 에 설치하세요. 다른 위치에 설치했다면, 같은 cmd 창에서 아래 줄로 위치를 알려 준 뒤 Setup-SUPRA-Tex.cmd 를 실행합니다.

set SUPRATEX_PYTHON=E:\원하는경로\python.exe

- Setup 에서 "This SUPRA-Tex is a different version" : 3번의 git checkout 줄을 실행하지 않은 것입니다. SUPRA-Tex 폴더에서 그 줄을 실행하고 Setup 을 다시 실행하세요.

- Setup 에서 "PyTorch cannot see the NVIDIA GPU" : 그래픽 드라이버를 최신으로 업데이트하세요.

- Start 실행 시 "Setup has not been run" : Setup-SUPRA-Tex.cmd 를 먼저 실행하세요.

- 브라우저에 화면이 안 열리고 실행 창에 "포트 8390 을 쓸 수 없습니다" : 워크벤치가 이미 켜져 있는 것입니다. 브라우저에서 http://127.0.0.1:8390 을 여세요.

- module 'ast' has no attribute 'Num' : Triton 이 다른 버전으로 설치된 것입니다. Setup-SUPRA-Tex.cmd 를 다시 실행하세요.

- no kernel image is available for execution on the device : CUDA 확장 파일이 다른 것으로 설치된 것입니다. Setup-SUPRA-Tex.cmd 를 다시 실행하세요.

- CUDA out of memory : 그래픽카드를 쓰는 다른 프로그램을 모두 끄고 다시 실행하세요.

- 겹침(IoU)이 낮음 : 메시 정면 방향, 이미지와 같은 물체인지, 배경이 제대로 지워졌는지 확인하세요.

- 텍스처가 어긋나 보임 (눈, 코, 입이 밀림 등) : 메시와 이미지의 형태가 다른 경우입니다. 6번처럼 Pixal3D 나 Idol 메시를 쓰면 가장 잘 맞습니다.

- 아래 경고들은 로그에 나와도 결과와 상관없으니 무시하세요.
+ huggingface_hub cache-system uses symlinks
+ Xet Storage is enabled for this repo, but the 'hf_xet' package is not installed
+ Using torch.cross without specifying the dim arg is deprecated
